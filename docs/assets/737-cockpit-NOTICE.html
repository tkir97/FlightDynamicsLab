Boeing 737-800 cockpit

Created by hakai315. Original model: Boeing 737-800 Cockpit on Sketchfab. Licensed under CC BY 4.0, as recorded in the supplied GLB metadata.

The supplied file was optimized using glTF Transform 4.5.1: equivalent vertices/materials were deduplicated, meshes were joined, and geometry was quantized and compressed with Meshopt. Geometry was not simplified. The original upload is unchanged. The optimized copy is available here.

This is a cockpit interior, not an exterior airliner model. Switches remain decorative. Both original yokes have been separated into pitch-column and roll-wheel pivot groups and animated from pilot input. The ±10° column and ±70° wheel travel are visual approximations, not measured 737 linkage geometry. Five main screen surfaces are overlaid with live flight, navigation and engine displays using JSBSim telemetry. Flight dynamics use the generic JSBSim 737 configuration, not validated 737-800 data.

Rendering uses Three.js 0.186.1 and its GLTFLoader/MeshoptDecoder. See Three.js MIT license and Meshoptimizer MIT license.
