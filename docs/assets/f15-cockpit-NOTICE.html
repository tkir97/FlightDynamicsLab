F-15 cockpit asset

This simulator uses the user-supplied f15.glb, exported with Blender's glTF exporter. The embedded geometry and textures are preserved in f15-cockpit.glb.

The supplied export's node and texture names match the FlightGear F-15C/D cockpit discussed when selecting this asset. FlightGear credits Richard Harrison, Enrique Laso and Gene Buckle; its aircraft page lists GPL version 2 or later. The uploaded GLB contains no author or licence metadata, so these credits identify the discussed upstream project rather than independently authenticate every uploaded component.

Aircraft description and licence listing · Upstream source · GPL version 2

Runtime changes: choose a front-seat viewpoint, hide repeated/unpositioned assemblies, adjust HUD-glass transparency, place live radar/flight/engine screen surfaces, and animate the supplied stick meshes. Switches and other instruments remain static. This is not a validated replica of a specific F-15 avionics fit.
