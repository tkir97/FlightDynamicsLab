Reference configuration

Working validation target: clean F-15C, gear up, no external stores, two F100-PW-220 engines, subsonic flight. Weight, centre of gravity, atmosphere, control mode and input history must match each reference test. This is a selected target, not a configuration already established by our model.

Current simulator: generic JSBSim F-15 with PW-229 engines, approximately 33,230 lb initial gross weight, 5,000 lb fuel, gear up and speedbrake stowed. It has approximate control augmentation and the 3.2× lateral-authority tuning. It is not yet a matched F-15C/PW-220 model.

Documented features and remaining estimates

NASA TM-72861, appendix pp. 12–13, documents pitch CAS authority of ±10° with reduction beyond mechanical commands of +5°/−19°, yaw CAS authority of ±5°, and washed-out pitch-rate feedback. These features now constrain our estimated controller. The pitch limiter taper and washout time constants are approximations; pilot commands and limited corrections are separate.

Roll gains, the 172°/s command, the 3.2× combined lateral moment, virtual-stick gearing, engine maps, and aerodynamic derivatives remain estimates. Differential stabilators and mechanical gearing schedules are not separately modeled. The native model's small yaw damper remains active in addition to the limited correction. No measured tracking trace has been replayed.

Reference-data review

What must happen before validation

  1. Obtain a numeric or carefully digitized trace for the selected variant, with source page/figure and uncertainty.
  2. Establish matching engine, mass/inertias, CG, configuration, altitude, Mach, atmosphere and control-system mode. Implement measured stick force/displacement or surface input, rather than equating it with a keyboard button.
  3. Replay the actual input history and compare roll/pitch rates, surface motion, load and damping. Report timing error, RMSE, peak error and source uncertainty.
  4. Fit parameters using one subset; test unchanged parameters against separate maneuvers and flight conditions.

Until then, the 3.2× roll factor and augmentation gains remain handling-tuning choices. The NASA control-system description supports the architecture and authority limits above; controller gains were checked for stable simulated response, not fitted to measured flight traces.

Reproduction and source fingerprints

Run npm run validate:f15 in the simulator source checkout. Runs use the shipped WASM at 240 Hz; samples are exported at 20 Hz. No random turbulence is enabled. Generated files identify the exact source hashes.
